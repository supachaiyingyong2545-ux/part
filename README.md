# DMSc CONNECT 2026 — Idea Network

**ระบบระดมความคิดเห็นแบบเรียลไทม์สำหรับเชื่อมโยงความคิด**

"ทุกความคิดเห็น เชื่อมโยงสู่การเปลี่ยนแปลง"

---

## 🎯 คุณลักษณะหลัก

✅ **หน้าโทรศัพท์** - ผู้เข้าร่วมสแกน QR Code และส่งความคิดเห็น  
✅ **จอแสดงผลแบบเรียลไทม์** - แสดงความคิดเห็น 5 รูปแบบสลับ  
✅ **เครือข่ายความคิด** - ฟองความคิดเชื่อมโยงกัน  
✅ **โหวตถูกใจ** - ผู้เข้าร่วมกดหัวใจความคิดเห็น  
✅ **บันทึก Google Sheets** - บันทึกข้อมูลอัตโนมัติ  
✅ **รองรับ 400+ ผู้ใช้** - WebSocket สำหรับการสื่อสารแบบสองทาง

---

## 🚀 เริ่มต้นใช้งาน

### 1. ติดตั้ง Dependencies

\`\`\`bash
npm install
\`\`\`

### 2. ตั้งค่า Environment

\`\`\`bash
cp .env.example .env
\`\`\`

### 3. รัน Server

\`\`\`bash
npm start
\`\`\`

Server จะเริ่มที่ `http://localhost:3000`

---

## 📱 หน้าจอ

- **หน้าโทรศัพท์** (`/`) - ผู้เข้าร่วมส่งความคิดเห็น
- **จอแสดงผล** (`/display`) - แสดงความคิดเห็นแบบเรียลไทม์ 5 โหมด
